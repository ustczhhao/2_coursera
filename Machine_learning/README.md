# Machine Learning

This directory collects selected materials from Andrew Ng’s foundational **Machine Learning** coursework on Coursera. It serves as an organized record of technical study in core machine learning concepts, combining assignments, course materials, notes, and certificate documentation.

## Contents

The current directory includes materials such as:

- **Assignment**  
  Selected coursework assignments and related exercise files.

- **Course content**  
  Lecture-related materials and supporting course documents organized by topic or week.

- **Course_note.pdf**  
  Consolidated course notes for study and review.

- **Coursera_certificate.pdf**  
  Course completion certificate.

- **MLY-zh-cn.pdf**  
  Additional reference material associated with the course.  
 
## Focus Areas

The materials in this directory reflect study and practice in foundational machine learning topics, including:

- supervised learning methods;
- regression and classification concepts;
- model fitting and evaluation;
- algorithmic foundations of machine learning;
- structured technical learning through course-based exercises and notes.

## Purpose

This directory is intended as part of a broader technical learning portfolio. Its purpose is to document formal coursework, reinforce conceptual understanding, and preserve selected learning materials in an organized and reproducible manner.

## Note

This directory is presented as a coursework archive rather than a standalone project repository. It complements other materials in this repository related to deep learning study and broader AI-focused technical development.
