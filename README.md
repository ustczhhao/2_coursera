# 2_coursera

This repository collects selected coursework materials completed through structured online learning on Coursera. It serves as an organized archive of technical study in machine learning and deep learning, including selected assignments, course materials, notes, and certificates.

The current repository includes materials from Andrew Ng’s **Machine Learning** course and the **Deep Learning Specialization** series. It is intended to document ongoing technical development and will continue to expand as additional coursework is completed and organized.

## Repository Scope

This repository is designed to provide a structured record of formal online coursework in machine learning and deep learning. Depending on the course and module, contents may include:

- selected assignments and coding exercises;
- course notes and lecture-related materials;
- selected supporting documents and learning materials;
- course completion certificates.

The repository is intended as a technical learning archive rather than a standalone project repository, and reflects continued study and hands-on engagement with core AI concepts and methods.

## Current Contents

The current repository includes materials related to:

- **Machine Learning**  
  Coursework based on Andrew Ng’s foundational machine learning curriculum, including assignments, notes, and supporting course materials.

- **Deep Learning Specialization**  
  Materials from the Deep Learning Specialization sequence, including selected coursework files, notes, and related learning materials across multiple courses.

## Focus Areas

The coursework represented in this repository supports continued development in areas such as:

This repository is intended as part of a broader technical portfolio and reflects continued effort to strengthen foundations in machine learning and deep learning through formal coursework. It highlights:
